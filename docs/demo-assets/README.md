# デモ用画像アセット

プロモーションデモ(UCCHAU利用デモ / LUNÉA LP)で使う商品画像の置き場です。

- ここに画像(png / jpg / webp)をアップロードしてください
- ファイル名は自由ですが、用途が分かる名前を推奨:
  - `concept-a.png` … コンセプトA(アンカー)
  - `concept-b.png` / `concept-c.png` … コンセプトB / C
  - `hero.png` … LPメインビジュアル
  - `lotion.png` / `serum.png` / `cream.png` … ラインナップ用
- アップロード後、Claudeに「画像を入れたよ」と伝えるとデモページに反映されます

注意: このリポジトリは公開のため、ここに置いた画像は誰でも閲覧できます。
