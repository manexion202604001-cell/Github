旧字体OCR転記ツール舊字體 → 新字体

旧字体で書かれた文書の画像・PDFを読み取り、新字体に変換してスプレッドシートへ自動転記します。
すべてブラウザ内で処理され、画像が外部サーバーへ送信されることはありません。

スクリーンショットを Ctrl+V / ⌘V で直接貼り付けることもできます
※ 初回のOCRは認識エンジン(約15MB)のダウンロードに少し時間がかかります

4スプレッドシートへ出力

🔗 Googleスプレッドシートへ直接自動転記する(任意設定)

Google Apps Script のWebアプリURLを設定すると、ボタン1つでシートに行を追記できます。 設定方法は README を参照(所要5分)。URLはこのブラウザにのみ保存されます。

📖 変換辞書を確認・カスタマイズする

標準辞書には常用漢字の旧字体 約330字を収録しています。下の欄に「旧字=新字」の形式で1行ずつ追加すると、独自の変換ルール(複数文字の語句も可)を登録できます。このブラウザに自動保存されます。
