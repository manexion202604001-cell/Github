AI Product Plan Generator

Pick your conditions and we generate an OEM product concept based on EC mall trend data, along with 3 product image concepts. Set an AI API key and AI actually generates the plan in real time; without a key, a sample is shown. If you also set an image generation API key, the product images become actual AI-generated images instead of package mockup diagrams. Product and brand names are always fully original coinages that never duplicate any existing brand.

ℹ️ Running in sample mode (no AI API key set)

Enter your own AI API key and the "Generate plan" button will have AI actually generate an OEM product concept from EC mall trend data.
The key is stored only in this browser (localStorage) and is sent directly from your browser to the AI API provider. It is never sent to or stored on this site's servers. API usage fees are billed to your own API account. Do not use this on a shared computer.
Get an API key here →

ℹ️ Showing mockups (no image generation API key set)

Enter your own Google AI Studio API key and the product images will be created as actual AI-generated images by Gemini 2.5 Flash Image ("Nano Banana") instead of package mockup diagrams.
The key is stored only in this browser (localStorage) and is sent directly from your browser to Google's Gemini API. It is never sent to or stored on this site's servers. API usage fees are billed to your own Google account. Do not use this on a shared computer.
Get a Google AI Studio API key here →

ℹ️ Direct mode — generation calls the AI APIs straight from this browser

Manage plan generation with n8n: set the production webhook URL of the bundled workflow (n8j-bridge/n8n/k2j-product-planning.json in this repository — import it into your n8n, fill in the credentials, activate) and the ✨ Generate button will run through your n8n instance instead of calling the AI APIs from the browser.
In n8n mode, API keys live only in n8n's credential store (nothing in this browser), every run is logged in n8n's execution history with retries and error handling, and the workflow fetches the live Rakuten ranking, generates the concept with Claude, and renders the 3 product images with Nano Banana server-side.
The URL is stored only in this browser (localStorage). If the n8n call fails, generation automatically falls back to direct browser mode.

Analyzing EC mall trend data and generating a product concept and image concepts…

Set an image search engine API key and search engine ID, and the feed will prioritize real image search results from design reference sites and actual products (without keys, the feed still works using key-free sources of real photos).
The keys are stored only in this browser (localStorage) and are sent directly from your browser to the search API provider. They are never sent to or stored on this site's servers. We strongly recommend setting an "HTTP referrer restriction" on the key in the API console so that only this site's URL is allowed.
